Contenido audiovisual
--------------------
Coloque aquí sus fotos y videos para el panel deslizante.

- fotos/  → imágenes (jpg, png, webp)
- videos/ → videos (mp4, webm)

Luego referencie los archivos en el código (page.tsx, array contenidoAudiovisual) usando rutas como:
  /audiovisual/fotos/nombre.jpg
  /audiovisual/videos/nombre.mp4
